# 🌸 Kawaii WCAG Audit Pro 💜✨

Profesjonalne narzędzie do audytowania dostępności cyfrowej (WCAG 2.2 / EN 301 549) w uroczej, fioletowej oprawie.

## ✨ Kluczowe Funkcje

### 📂 Zarządzanie Projektami
- **Wiele Audytów**: Możliwość tworzenia osobnych audytów dla różnych aplikacji.
- **Inteligentne Tworzenie**: Przy tworzeniu nowego audytu możesz wybrać, czy chcesz zacząć od zera, czy przenieść obecną pracę do nowego projektu.
- **Wersjonowanie**: Twórz "zamrożone" wersje (v1, v2...) swoich audytów, aby śledzić postępy w czasie.

### 🔍 Filtrowanie i Analiza
- **Trzystopniowe Filtry**:
  1. Kliknięcie: **Wybierz** (Include) - tło miętowe.
  2. Drugie kliknięcie: **Wyklucz** (Exclude) - przekreślenie i tło różowe.
  3. Trzecie kliknięcie: **Neutralny** (Reset).
- **Podział na Obszary**: Możliwość przypisania kryterium do wielu zespołów (Dev, Content, Design). Każdy zespół może filtrować zadania "dla siebie".

### 🛠️ Edycja i UX
- **Tryb Podglądu (View Mode)**: Bezpieczne przeglądanie audytu z możliwością odblokowania konkretnego wiersza (🔓) do szybkiej poprawki.
- **Badge Popupy**: Obszary i priorytety wybierane są przez interaktywne popupy z badge'ami.
- **Autozapis**: Każda zmiana jest automatycznie zapisywana, o czym informuje "sticky" wskaźnik w rogu ekranu.

### 📄 Raporty i Eksport
- **HTML**: Samowystarczalny plik z pełnym stylowaniem.
- **CSV**: Dane gotowe do dalszej obróbki w arkuszach kalkulacyjnych.
- **PDF**: Czytelny wydruk prosto z przeglądarki.

## 🚀 Jak zacząć?

1. Uruchom serwer: `cd server && node server.js`.
2. Otwórz w przeglądarce: `http://localhost:3000`.
3. Aplikacja zawsze otwiera się na projekcie `default` w wersji `draft`.
4. Wpisz nazwę swojej aplikacji i kliknij **🆕 Nowy Audyt**, aby stworzyć dedykowany projekt.

## 🎨 Estetyka
Projekt wykorzystuje paletę **Kawaii Violet** (#a797ff) z elementami różu i mięty. Zaokrąglone kształty, czytelne kropki priorytetów (🔴🟠🟡) oraz intuicyjne "status switchery" sprawiają, że praca z audytem jest nie tylko efektywna, ale i przyjemna dla oka.
